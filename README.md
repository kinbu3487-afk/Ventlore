# Ventlore

Chào mừng bạn đến với dự án **Ventlore**!

Ventlore là một dự án ứng dụng web hiện đại được phát triển với định hướng sử dụng Node.js và Next.js.

## 📁 Cấu trúc thư mục
- `docs/`: Thư mục chứa tài liệu chung của dự án.
  - `source/`: Tài liệu nguồn, ghi chú thiết kế và bản thảo.

## 🚀 Trạng thái
Dự án đang trong giai đoạn khởi tạo cấu trúc cơ bản và chuẩn bị tài liệu.
