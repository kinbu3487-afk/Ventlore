# Ventlore Brand Kit v0.1

Mở 03_Guidelines/Ventlore_Brand_Guide_v0_1.pdf để xem toàn bộ quy tắc.

- 01_Logos: logo sáng/tối và avatar PNG có nền cố định.
- 02_Brand_Board: bản tổng thể minh họa ứng dụng.
- 04_UI_Tokens: JSON và CSS cho giao diện sáng; không thay thế logic ứng dụng.
- 05_Fonts: bốn độ đậm Be Vietnam Pro và giấy phép OFL.
- 06_Creative_Brief: định hướng và prompt sáng tạo.

Sử dụng trực tiếp ảnh ở kích thước phù hợp với độ phân giải có sẵn. Chưa có master vector, PNG nền trong suốt hoặc favicon 16 px. Bảng màu chuẩn được ghi trong tokens. Bộ này chưa phải bộ file chế bản in.
